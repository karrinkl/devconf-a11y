# DEVCONF 2026 - доступность (a11y) лендинга IT-конференции по WCAG

Лабораторная работа № 30. Обеспечение веб-доступности для ключевых
компонентов веб-приложения согласно стандартам WCAG.

Вариант 2: лендинг IT-конференции. Проект продолжает ЛР № 29
(`devconf-tests`): аудит и исправления выполнены для навигационного
меню, аккордеона FAQ и карточек спикеров.

## Результаты аудита

| Страница | Lighthouse до | Lighthouse после | axe-core до | axe-core после |
|---|---|---|---|---|
| `/` | 100 | 100 | 0 нарушений | 0 нарушений |
| `/schedule` | 100 | 100 | 0 | 0 |
| `/speakers` | 98 | 100 | 1 (heading-order) | 0 |
| `/speakers/kovalev` | 100 | 100 | 0 | 0 |

Автоматические инструменты нашли одно нарушение. Остальные проблемы
выявлены ручной проверкой с клавиатуры и анализом дерева доступности.

## Что исправлено

| Компонент | Проблема | Исправление | Критерий WCAG |
|---|---|---|---|
| Аккордеон FAQ | Стрелки, Home и End не перемещали фокус между заголовками | Клавиатура по шаблону WAI-ARIA Accordion, уровень заголовков задаётся свойством `headingLevel` | 2.1.1 |
| Аккордеон FAQ | `aria-expanded` уже был (ЛР № 29), проверена связка `aria-controls` и `role="region"` с `aria-labelledby` | Подпись панели ссылается на кнопку заголовка | 4.1.2 |
| Меню | Кольцо фокуса на тёмном меню с контрастом 1,32:1, у текущего пункта фокус не виден совсем | Контур 3 px цвета #22d3ee (9,9:1), `:focus-visible` для всех интерактивных элементов | 2.4.7, 1.4.11 |
| Меню | Нет ссылки пропуска меню и `aria-current` | Ссылка «Перейти к основному содержимому», `aria-current="page"`, ориентиры `header > nav[aria-label]` | 2.4.1, 1.3.1 |
| Карточки спикеров | Заголовки h3 сразу после h1, фото читалось как «Фотография спикера: имя» перед тем же именем в заголовке, у заглушки неправдивый alt | Заголовки h2, список `ul/li`, декоративное фото с `alt=""`, подробный alt на странице спикера | 1.3.1, 1.1.1 |
| Карточки спикеров | Звёздочка раньше имени в порядке Tab, подпись кнопки менялась вместе с состоянием | Кнопка после текста в DOM, постоянная подпись и `aria-pressed` | 2.4.3, 4.1.2 |
| Плашка SSR/SSG | Статичный текст с `role="alert"` зачитывался при каждой загрузке | `role="note"` | 4.1.3 |
| Форма регистрации | Ошибка не связана с полем, `aria-describedby` ссылался на удалённый элемент | `aria-invalid`, `aria-describedby` на текст ошибки, `role="alert"`, фокус в поле | 3.3.1, 4.1.2 |
| Избранное | Изменение счётчика не озвучивалось | `role="status"` | 4.1.3 |
| Расписание | У таблицы не было подписи | Скрытый `<caption>` | 1.3.1 |

## Тесты

```bash
npm install
npx playwright install chromium

npm test                 # 40 unit-тестов Jest, в том числе клавиатура аккордеона и ARIA
npm run test:a11y        # аудит axe-core всех страниц и клавиатурные сценарии
npm run test:e2e         # все E2E-тесты, включая «Поиск спикера» из ЛР № 29
npm run test:e2e:ui      # интерфейс Playwright UI
```

| Файл | Что проверяет |
|---|---|
| `e2e/a11y.spec.js` | 4 страницы без нарушений axe-core по WCAG 2.0-2.2 A/AA и best-practice |
| `e2e/keyboard.spec.js` | ссылка пропуска меню, меню с Tab и Enter, видимый фокус, аккордеон со стрелками |
| `__tests__/unit/Accordion.test.jsx` | состояние, ARIA и клавиатура аккордеона (14 тестов) |
| `__tests__/unit/a11y-components.test.jsx` | ошибки формы, кнопка «В избранное», alt фото, `role="note"` (6 тестов) |

Если на Arch Linux скачанный Playwright браузер не запускается:

```bash
sudo pacman -S chromium
CHROMIUM_PATH=/usr/bin/chromium npm run test:a11y
```

## Ручная проверка

1. Открыть сайт после `npm run build && npm run start` (http://localhost:3000).
2. Нажать Tab: первой появляется ссылка «Перейти к основному содержимому».
3. Пройти меню Tab и Shift+Tab: вокруг каждого пункта виден голубой контур.
4. В блоке «Частые вопросы» перемещаться стрелками вверх и вниз, Home, End,
   открывать пункты Enter или пробелом.
5. Lighthouse: DevTools, вкладка Lighthouse, категория Accessibility.
   Axe DevTools: расширение для Chrome или Firefox, кнопка Scan all of my page.
6. Скринридер на Linux: Orca (`sudo pacman -S orca`, запуск командой `orca`),
   на Windows NVDA.
